# Stage 2 — run guide (G076 / MP136)

Use Python 3.11 or 3.12.

## Install
```bash
python -m venv .venv
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Verify untouched source data
```bash
python -c "import hashlib,pathlib; [print(n,hashlib.md5((pathlib.Path('data/raw')/n).read_bytes()).hexdigest()) for n in ['train.csv','later.csv']]"
```
Expected MD5: train `b11f97737d9fe5089d73ca9957ae052a`; later `34674b837c639e9c1ef5efbc9625926b`.

## Clean, test, train
```bash
python -m src.data_processing
pytest -q
python -m src.train
```

The cleaning script drops exact duplicates, removes post-delivery leakage, converts Tier-2 weight from grams to kg, trims text and parses dates. It preserves target values. The training script runs three distinct candidate settings, logs the original train.csv SHA-256 as `data_sha256` and validation MAE in each MLflow run, registers the best v1 candidate and sets alias `champion`.

After successful training, `mlflow.db`, `models/champion.joblib`, and `reports/stage2_training_summary.json` are created. Open MLflow with:
```bash
mlflow ui --backend-store-uri sqlite:///mlflow.db
```
Then browse `http://127.0.0.1:5000`.

**Important:** the DB, actual run IDs, model version, and metrics are generated by running the commands; this archive does not invent or pre-fill experiment evidence. Commit `mlflow.db` to GitHub as the handbook requires. The test suite uses in-memory sample data, not CSVs.
