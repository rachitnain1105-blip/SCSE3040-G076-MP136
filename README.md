## Project Overview

This project focuses on predicting parcel delivery duration in days for deliveries associated with Patna using machine learning and MLOps practices.

The project includes data version control, data investigation and cleaning, model training, experiment tracking, model deployment, testing, monitoring, and prediction.

## Repository Structure

- `data/` – Dataset files and processed data
- `src/` – Data processing and machine learning source code
- `reports/` – Data investigation findings
- `models/` – Model files
- `tests/` – Project tests
- `api/` – API-related files
- `k8s/` – Kubernetes configuration files
